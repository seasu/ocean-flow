# 洋流：起源 · Mobile Web Prototype

《洋流》的第一個可玩原型，主題是「透過遊戲讓大家了解台灣的美」：在一座方塊風格的台灣島上，收集「靈光」、乘著東岸黑潮、喚醒三處靈脈，最後走進山門。

- 純 HTML + JavaScript（ES modules），自己寫的小型 WebGL 方塊渲染器，**不依賴任何函式庫、不需要建置**
- 手機直式、橫式都能玩；觸控搖桿＋跳躍＋感知按鈕
- 角色依「洋流 Ocean Currents」設定圖：藍色款＝玩家阿流，橘色款＝夥伴阿汐
- 音效與環境音用 WebAudio 即時合成，沒有音檔

## 玩法

| 操作 | 手機 | 電腦 |
|---|---|---|
| 移動 | 左半邊拖曳（虛擬搖桿） | WASD／方向鍵 |
| 轉視角 | 右半邊拖曳 | J／L |
| 跳 | 「跳」按鈕（按住可連跳） | 空白鍵 |
| 感知 | 「感知」按鈕 | E |

1. 收集發光的靈光（每處靈脈需要 3 點）。按「感知」會掃出一圈波紋、讓靈光更明顯，並告訴你最近的靈脈在哪個方向。
2. 喚醒三處靈脈：北邊城市的廣場（城之回聲）、東海小島（海之流痕，跳進洋流讓它帶你往北）、中央山脈最高峰（山之鐘聲）。站在節點上幾秒就會啟流。
3. 每喚醒一處，世界就往靈界多偏一層：天色轉深、地面浮現光脈、浮島從雲下升起。
4. 三處都喚醒後山門開啟，走進西側平原的紅色牌樓即完成。
5. 「台灣之美」圖鑑：島上放了八處真實地景，走近就會跳出介紹卡並收進圖鑑（各＋1 靈光）：台北 101、龜山島、黑潮、太魯閣峽谷、日月潭、玉山、阿里山神木、鵝鑾鼻燈塔。

## 本機執行

ES modules 需要經由 HTTP 開啟：

```sh
npx http-server -p 8080 .
# 開 http://localhost:8080 ；手機和電腦同網路時可用電腦的區網 IP
```

測試用網址參數：`?play` 跳過片頭、`?awake=2` 先喚醒兩處、`?at=sea|city|peak|gate` 傳送到該處。

## 部署

合併到 `main` 後，`.github/workflows/pages.yml` 會發佈到 GitHub Pages（需要在 repo Settings → Pages 把 Source 設為 GitHub Actions）。

## 檔案

- `index.html`：版面、HUD、片頭片尾
- `src/gl.js`：WebGL 方塊／水面／天空著色器
- `src/world.js`：島嶼、城市、山脈、黑潮、山門與節點的生成
- `src/avatar.js`：方塊角色與動作
- `src/main.js`：操作、鏡頭、任務流程、HUD
- `src/audio.js`：合成音效
