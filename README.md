# 洋流：起源 · 台北文化徑 × 山林徑的遊戲 MVP

《洋流》是一款手機網頁遊戲，用「玩遊戲」加上「實際走到景點」的方式，帶大家重新認識台北，也認識台灣的美。

## 為什麼做這個題目

這個專案是為了參加沈伯洋團隊舉辦的「市政 Debug 松」而做的（第 7 題・自訂主題，題目「[洋流] 透過遊戲讓大家了解台灣的美」）。

創意來自沈伯洋團隊的政見：**打造「首都文化徑及山林徑」，讓山林與歷史，共同成為台北的日常。**

政見指出的問題是：台北其實是被群山環抱的盆地，城區的歷史和山林的地景本來就是一體的。但是古蹟常被當成單一景點，步道常被當成單純運動的路線，彼此的關聯很難被看見，也很難拼成完整的台北故事。政見想用「點 → 線 → 面」的方式，把散落各處的老建築、歷史故事、產業記憶、山林步道和生活場景串起來：

- **文化徑**有四大主題：城市歷史記憶、現代台北、產業文化遺跡、多元族群
- **山林徑**以北劍潭、東象山、南貓空三座登山觀光中心為節點，打造亞洲第一觀光登山城
- 重新檢視步道系統、路徑品牌化與數位治理、親子同行
- 目標是讓文化資產從「只能被參觀的對象」，變成市民走得到、用得到、也願意停下來理解的日常資源

## 這個專案想做到什麼

**目標：透過遊戲與實際景點遊歷，把「文化徑 × 山林徑」這個政策落成一個看得到、玩得到的想法。** 這個 MVP 用來呈現概念。

政見說要讓文化路線「看得懂、走得到、能持續經營」，也要有數位導覽。我們的回答是：把路線變成一段冒險。

- **走路就是玩法。** 遊戲的成長系統叫「走路修行」：在現實中走的每一公尺都會轉成修為，讓人有理由真的走出門。
- **在真實地點才會觸發。** 開門、城市故事這些「機緣」只在手機實際走到那個地點時才會發生；到了現場，景點小卡就是隨身的數位導覽。
- **從點到線、從城到山。** 第一階在城裡走一段文化徑（古蹟、產業遺跡），就會依序喚醒山林徑上的四獸山守門獸，對應政見裡「山與城的連結」，也就是「走一條路，認識台北這座城」。
- **故事比告示牌好記。** 每個地點用一段在地故事加上問答呈現，像五分埔地名的由來、士林的漳泉械鬥，讓古蹟不只是冷冰冰的物件。
- **由小到大。** Demo 從黑客松會場附近開始，接著擴大到台北各區，最後走向全台灣，和政見「先做示範路線、再逐步擴大」的推動藍圖同一個方向。

遊戲是獨立的 IP，世界觀裡不出現候選人、政黨或競選內容。設定上，台灣是第一個「啟流」的地方：洋流從台灣被發現，但不屬於台灣，之後的章節會流向亞洲、世界與更遠的地方。

## 兩個世界：現世 × 靈界

- **靈界**是一座方塊風格的台灣島。玩家（阿流）用搖桿在島上移動、收集發光的「靈光」，沿著東岸的黑潮北上，走到各道靈門。
- **現世**是真實的台北。打開定位後，右上角的「現世」雷達會顯示附近的機緣地點。走到地點半徑內，手機會震動，主畫面出現「進入機緣」按鈕。
- 兩邊互相連動：開著現世定位時，靈界裡的門要先在現世的對應地點觸發過一次才打得開。只想在島上玩，也可以不開定位。
- 任務卡、雷達和靈界地圖都有兩個按鈕：「導航」開 Google 地圖步行導航；「指引」留在靈界，用方向箭頭和地上的金光帶路。

## 玩法

| 操作 | 手機 | 電腦 |
|---|---|---|
| 移動 | 左半邊拖曳（虛擬搖桿） | WASD／方向鍵 |
| 轉視角 | 右半邊拖曳 | J／L |
| 跳 | 「跳」按鈕（按住可連跳） | 空白鍵 |
| 感知 | 「感知」按鈕 | E |

**走路修行**：現世模式算真實走的公尺數（搭車、騎車太快的不算），島上模式算角色走的步數。修為滿了，到任何機緣點就會突破境界：感流境 → 聚流境 → 化流境 → 御流境 → 歸流境。每升一境淨化力提高，前面的戰鬥會變輕鬆。

### 第一階・四獸靈門（會場周邊的文化徑）

台北 101 東側的四獸山，是城市之流與山之流交會的四個守門節點，要依序開啟：象門 → 虎門 → 豹門 → 獅門。每道門要 3 點靈光，開門前要先打一場「淨化之戰」，把門前失衡的濁流淨化回來（是淨化，不是打倒）。每座門一種玩法，每場大約 20 秒、單手就能玩：

| 門 | 特質 | 玩法 | 現世地點 |
|---|---|---|---|
| 象門 | 穩定・記憶 | 4×4 迷你數獨（用海、山、花、陽代替數字） | 華山1914（產業文化遺跡・舊酒廠） |
| 虎門 | 行動・爆發 | 連點（Tap Hero），集滿爆發條放出虎爪 | 台灣文學基地（齊東詩舍） |
| 豹門 | 敏捷・感知 | 畫符結印，一筆連起光點 | 濟南教會 |
| 獅門 | 威勢・領導 | 三消，連四個留下「流眼」清空整排 | 善導寺 |

每個機緣有星等（★～★★★），難度依玩法調整。輸了可以重來，也會提示「可以先去走一段路」。四印齊了，會播放全畫面的「四獸共鳴」動畫，開啟第二階。

### 第二階・台北城市故事（雷達目的地）

七個在地故事散在台北各處。走到現場（半徑 300 公尺），聽夥伴阿汐說完，先讀故事、再答 3 題，全對才算通關，故事會收進圖鑑，並得到 3 點靈光。城市故事只能在現世觸發。

| 地點 | 故事 |
|---|---|
| 五分埔 | 五戶人家合資分地，地名的由來 |
| 士林慈諴宮 | 漳泉械鬥後，在新的地方一起把街蓋回來 |
| 新莊老街 | 一府二鹿三新莊 |
| 萬華與加蚋仔 | 北、中、南三個萬華 |
| 大龍峒保安宮 | 古蹟修復 |
| 再春游泳池與明治橋 | 消失的橋 |
| 石牌商城 | 北投・石牌夜市 |

### 第三階・城海山三流

找齊城市故事、境界到化流境以上之後，島上的三處靈脈會甦醒，不分順序：城之回聲（龍靈）、海之流痕（龜山島・龜靈）、山之鐘聲（玉山・台灣黑熊靈）。三流歸一後，台北靈門開啟。

### 序章 BOSS：濁淵

台北靈門前擋著濁淵，是四獸影子揉成的濁流巨獸。挑戰要 6 點靈光，四關連戰（數獨 → 連點 → 畫符 → 三消），難度最高、要一次打完，輸了或離開會清空所有靈光。打贏就完成序章，畫面顯示「第一章・流域，敬請期待」，也可以重新體驗序章。

### 其他

- **濁影**：靈界地圖上有 5 隻被濁流附身的守門獸影子，靠近會追上來，碰到就開戰。贏了得 2 點靈光，輸了扣 2 點。
- **台灣之美圖鑑**：島上放了八處真實地景：台北 101、龜山島、黑潮、太魯閣峽谷、日月潭、玉山、阿里山神木、鵝鑾鼻燈塔。走近會跳出介紹卡並收進圖鑑。
- **成就**：依世界觀八章分區，目前開放序章的成就（四道門、四獸共鳴、城市故事、三流、濁淵）。點一下可以重播當時的過關動畫，後面七章先以灰色顯示。
- **世界觀**：故事分成八章，像一本書慢慢翻開：序章・起源 → 流域 → 連界 → 星航 → 萬象 → 歸源 → 新生 → 無界。島外的海上有後面七章的入口，目前上鎖。設定裡可以看世界觀章節頁、角色圖鑑、境界說明和個人資訊。
- **語言**：繁體中文、English、日本語，依瀏覽器語言自動選，也可以用 `?lang=zh|en|ja` 指定。英文、日文由團隊自行翻譯，待母語者校對。

## 現地地點與安全

第一階以黑客松會場（台北市中正區北平東路 30 號）為起點與終點，四道靈門排成一圈約 2 公里的步行路線。台北車站、監察院古蹟（在人行道欣賞）、光華數位新天地另外對應第三階的三流。

- 地點都選公共、可步行的場所，雷達上會一直提醒走人行道、注意來車。
- 座標寫在 `src/geo.js`（第一階）和 `src/stories.js`（城市故事），是事前估計的。到現場用 `?calib` 開啟，站在每個地點按「設為目前位置」就能校正，下方會印出可以貼回程式的座標。
- 台上展示時，可以到設定打開「模擬定位」（預設關閉），雷達清單每一列會多一個走路圖示，點了就走過去。設定裡的「Demo 階段」可以直接跳到第一、二、三階。

## 如果市府上任 100 天內要落地，需要做什麼

目標：把這個原型變成四獸山與周邊文化徑的**手機數位導覽**，搭配象山登山觀光中心推廣「走一條路，認識台北這座城」。下面的局處分工、資料與成本都是**團隊的估計**，需要與各局處確認。

**參與局處**

| 局處 | 負責 |
|---|---|
| 觀光傳播局 | 主責單位；景點介紹與照片授權（臺北旅遊網）、推廣活動、多語翻譯 |
| 工務局大地工程處 | 親山步道資料、路況與封閉公告、步道上的安全點位與標示 |
| 文化局 | 文化徑地點（古蹟、歷史建築、文學基地）的內容審訂 |
| 資訊局 | 開放資料介接、資安與個資檢測、網站上架 |

**需要的資料**

- 臺北旅遊網景點 Open API（已接上，見下方「景點介紹與照片」）
- 台北市親山步道路線、出入口與里程資料（大地工程處）
- 步道即時路況與封閉公告（讓遊戲在步道封閉時自動停用該點）
- 文化資產／古蹟清單與座標（文化局）
- 各點位的實地 GPS 校正座標與照片（現場踏查）

**100 天時程**

| 期間 | 工作 |
|---|---|
| 第 1–30 天 | 確認主責局處與資料授權；選定四獸山步道口與文化徑點位；完成安全評估（人行道、避開車道與施工） |
| 第 31–60 天 | 現場踏查校正座標、補拍豹山／獅山等缺照片的點位；文案審訂與中英日韓翻譯；接上步道路況資料 |
| 第 61–90 天 | 無障礙與資安檢測；在步道口與象山登山觀光中心設置 QR Code 立牌；小規模市民試玩 |
| 第 91–100 天 | 正式上線、搭配週末走讀活動推廣；收集使用數據（匿名、不存位置軌跡） |

## 景點介紹與照片（臺北旅遊網 Open API）

`tools/fetch-taipei-travel.mjs` 會從 [臺北旅遊網 Open API](https://www.travel.taipei/open-api) 抓四獸山與現世機緣地點的官方介紹和照片（每處最多 3 張），存到 `data/taipei-travel.json` 與 `data/photos/`。遊戲裡點開景點小卡就會看到，並標示出處（臺北市政府觀光傳播局）。

這個開發環境連不到 travel.taipei，所以由 `.github/workflows/taipei-data.yml` 在 GitHub Actions 執行並提交回分支；要更新資料，可以到 Actions 手動執行，或在本機跑 `node tools/fetch-taipei-travel.mjs`。資料使用前請再確認臺北市政府的開放資料授權條款。

## 本機執行

ES modules 需要經由 HTTP 開啟：

```sh
npx http-server -p 8080 .
# 開 http://localhost:8080 ；手機和電腦同網路時可用電腦的區網 IP
```

測試用網址參數：

| 參數 | 作用 |
|---|---|
| `?play` | 跳過片頭（加 `?geo` 改用現地模式） |
| `?nofilm` | 不播介紹影片 |
| `?demo=n` | 直接跳到第 n 階 |
| `?awake=n` | 先喚醒前 n 處（最多 7） |
| `?realm=n` | 直接設定境界 |
| `?at=sea\|city\|peak\|gate` | 傳送到該處 |
| `?nobattle` | 跳過戰鬥 |
| `?game=sudoku\|taphero\|sigil\|match3` | 每一門都用同一種玩法 |
| `?calib` | 現場校正地點座標 |

## 部署

合併到 `main` 後，`.github/workflows/pages.yml` 會發佈到 https://seasu.github.io/ocean-flow/ 。第一次使用前，要到 repo 的 Settings → Pages 把 Source 設為「GitHub Actions」。
