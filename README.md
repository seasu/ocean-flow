# 洋流：起源 · Mobile Web Prototype

《洋流》的第一個可玩原型，主題是「透過遊戲讓大家了解台灣的美」：在一座方塊風格的台灣島上，收集「靈光」、乘著東岸黑潮、依序開啟四獸靈門，四獸共鳴後走進台北靈門。

- 純 HTML + JavaScript（ES modules），自己寫的小型 WebGL 方塊渲染器，**不依賴任何函式庫、不需要建置**
- 手機直式、橫式都能玩；觸控搖桿＋跳躍＋感知按鈕
- 角色依「洋流 Ocean Currents」設定圖：藍色款＝玩家阿流，橘色款＝夥伴阿汐
- 第一次開啟會自動播放《洋流：起源》介紹影片（`video/intro.mp4`，由 `ocean-flow-origin/films/` v2 動態版壓成 720p；手機直拿時改播直式版 `video/intro-portrait.mp4`，由 `film-v1/build_portrait.py` 從同一組關鍵畫面裁出 9:16 並水平平移），可略過；之後從片頭或片尾的「觀看介紹影片」重看
- 背景音樂與結尾曲是 Gemini Lyria 3.5 生成的管弦樂（`audio/`）；海潮環境音與音效（豎琴、鋼片琴、弦樂、鐘聲，加上殘響）用 WebAudio 即時合成
- 介面、對話與景點介紹支援繁體中文、English、日本語：依瀏覽器語言自動選擇，片頭與片尾可切換，也可用 `?lang=zh|en|ja` 指定。英文與日文為團隊自行翻譯，待母語者校對；景點官方介紹取自臺北旅遊網 Open API 的英文、日文版

## 玩法

| 操作 | 手機 | 電腦 |
|---|---|---|
| 移動 | 左半邊拖曳（虛擬搖桿） | WASD／方向鍵 |
| 轉視角 | 右半邊拖曳 | J／L |
| 跳 | 「跳」按鈕（按住可連跳） | 空白鍵 |
| 感知 | 「感知」按鈕 | E |

**走路修行**：走的路會轉成「修為」，現地模式算真實走的公尺數（模擬定位也算，搭車騎車太快的不算），島上算角色走的步數。修為滿了，到任何機緣點就會突破境界：感流境 → 聚流境 → 化流境 → 御流境 → 歸流境。每升一境，淨化之戰多一步。

1. 收集發光的靈光（每道靈門需要 3 點）。按「感知」會掃出一圈波紋、讓靈光更明顯，並告訴你下一道靈門在哪個方向。
2. 第一階「四獸靈門」：台北 101 東側的四獸山是城市之流與山之流交會的四個守門節點，要依序開啟——第一印象門（穩定・記憶・承載）→ 第二印虎門（行動・勇氣・爆發）→ 第三印豹門（敏捷・感知・身法）→ 第四印獅門（威勢・領導・氣運）。順序不對，靈門不會回應。
3. 淨化之戰：每道獸靈門開啟前，門前會出現一團「濁流」，代表流的失衡。打贏是把濁流淨化回來，不是殺死它。四座門各用一種玩法，呼應各自的特質，每場大約 20 秒、單手就能玩；輸了可以重來，而且下一次會變簡單：
   - 象門（記憶・穩定）：4×4 迷你數獨，用海、山、花、陽代替數字。填對一格就打濁流一下，錯三次重來。
   - 虎門（行動・爆發）：連點。越快越痛，偶爾會心一擊；集滿爆發條放出虎爪，守護獸也會定時出手。
   - 豹門（敏捷・感知）：畫符結印。照數字順序一筆連起光點，四道符淨化濁流。
   - 獅門（威勢）：三消。連四個留下「流眼」清空整排整列；濁流每兩步丟濁塊，在旁邊消除就能洗掉。

   走路修行的境界越高，戰鬥越從容（數獨多失誤機會、連點和畫符多秒數、三消多步數）。島上充能完成或現地抵達點位時都會觸發；測試時加 `?nobattle` 可跳過，加 `?game=sudoku|taphero|sigil|match3` 可讓每一門都用同一種玩法。
4. 每開一印，世界就往靈界多偏一層：天色轉深、地面浮現光脈。
5. 四印齊了觸發「四獸共鳴」，台北靈門開啟，走進西側平原的紅色牌樓（現地模式則回到會場）即完成。城之回聲、海之流痕、山之鐘聲留在島上，作為第二階的預告。
6. 路線導引：任務面板的「🧭 帶我去」會在畫面下方顯示箭頭，用「在你左前方、還有 120 公尺」這種左右前後的說法帶路，不用東南西北。現地模式用手機指南針判斷前方，沒有指南針時用你最近走的方向；也可以一鍵開 Google 地圖步行導航。島上則以鏡頭朝向為前方。
7. 「台灣之美」圖鑑：島上放了八處真實地景，走近就會跳出介紹卡並收進圖鑑（各＋1 靈光）：台北 101、龜山島、黑潮、太魯閣峽谷、日月潭、玉山、阿里山神木、鵝鑾鼻燈塔。

## 呼應「文化徑 × 山林徑」

遊戲第一階把兩條路接在一起：在會場附近走一段**文化徑**（城市歷史記憶、產業文化遺跡的真實地點），就會依序開啟**山林徑**上的四獸靈門，對應「山與城的連結」和「走一條路，認識台北這座城」。每個地點的介紹小卡就是隨身的數位導覽。

## 現地探索（現世 × 靈界）

片頭選「走出去・現地探索」會打開定位，以黑客松會場（台北市中正區北平東路30號）為中心，在附近的真實地點觸發「機緣事件」。右上角「📍 現世」可以隨時打開靈脈雷達。

第一階的四道靈門排成一圈從會場出發的步行路線（約 2 公里）：

| 順序 | 地點 | 事件 |
|---|---|---|
| 第一印 | 華山1914 | 開啟象門 🐘 |
| 第二印 | 台灣文學基地（齊東詩舍） | 開啟虎門 🐯 |
| 第三印 | 濟南教會 | 開啟豹門 🐆 |
| 第四印 | 善導寺 | 開啟獅門 🦁 |
| — | 監察院古蹟（人行道）、台北車站、光華數位新天地 | 結下機緣，各＋2 靈光 |
| 終點 | 台北靈門（會場） | 四獸共鳴後，回到這裡打開台北靈門 |

順序不對的地點仍會顯示景點小卡，並提示下一印在哪裡。

- 走進地點半徑（60–80 公尺）內，手機會震動，雷達上出現「進入機緣」按鈕。
- 沒有定位權限或抓不到 GPS 時，自動改用**模擬定位**：點雷達上的地點或清單就會走過去，適合台上展示。雷達下方的開關也可以手動切換。
- 地點座標寫在 `src/geo.js`，是事前估計的。到現場用 `?calib` 開啟，站在每個地點按「設為目前位置」就會校正（存在這支手機的瀏覽器），下方會印出可以貼回 `src/geo.js` 的座標。
- 地點都選公共、可步行的場所；雷達上一直提醒走人行道、注意來車。

## 景點介紹與照片（臺北旅遊網 Open API）

`tools/fetch-taipei-travel.mjs` 會從 [臺北旅遊網 Open API](https://www.travel.taipei/open-api) 抓四獸山與現世機緣地點的官方介紹和照片（每處最多 3 張），存到 `data/taipei-travel.json` 與 `data/photos/`。遊戲裡點開景點小卡就會看到，並標示出處（臺北市政府觀光傳播局）。

這個開發環境連不到 travel.taipei，所以由 `.github/workflows/taipei-data.yml` 在 GitHub Actions 執行並提交回分支；要更新資料，可以到 Actions 手動執行，或在本機跑 `node tools/fetch-taipei-travel.mjs`。資料使用前請再確認臺北市政府的開放資料授權條款。

## 本機執行

ES modules 需要經由 HTTP 開啟：

```sh
npx http-server -p 8080 .
# 開 http://localhost:8080 ；手機和電腦同網路時可用電腦的區網 IP
```

測試用網址參數：`?play` 跳過片頭（`?geo` 改用現地模式）、`?awake=2` 先喚醒兩處、`?at=sea|city|peak|gate` 傳送到該處。

## 部署

合併到 `main` 後，`.github/workflows/pages.yml` 會發佈到 https://seasu.github.io/ocean-flow/ 。第一次使用前，要到 repo 的 Settings → Pages 把 Source 設為「GitHub Actions」。

## 檔案

- `index.html`：版面、HUD、片頭片尾
- `src/gl.js`：WebGL 方塊／水面／天空著色器
- `src/world.js`：島嶼、城市、山脈、黑潮、台北靈門與節點的生成
- `src/avatar.js`：方塊角色與動作
- `src/main.js`：操作、鏡頭、任務流程、HUD
- `src/battle.js`：開門前的淨化之戰（共用外框）
- `src/games/`：四種戰鬥玩法：數獨、連點、畫符、三消
- `src/audio.js`：合成音效

## 概念片製作檔案

`ocean-flow-origin/`：《洋流：起源》90 秒世界觀概念片的製作檔案（製作包、旁白稿、製作紀錄、角色設定圖、關鍵畫面、試音、配樂、影片與產生腳本），目錄說明見 [ocean-flow-origin/README.md](ocean-flow-origin/README.md)。影音與圖片直接存在 git 裡（每個檔案都在 GitHub 100 MB 上限內），影片各版本都保留在 `ocean-flow-origin/films/`。
