# 市政debug松（puma.taipei/hackathon）研究筆記

整理日期：2026-10-13。puma.taipei 被本環境的網路政策擋住，以下內容來自搜尋引擎對官網與報名頁的摘錄，**未直接讀到原頁**；標「未確認」的項目請以官網為準。

## 活動是什麼
- 名稱：市政debug松，主辦為沈伯洋競選辦公室（頁面標題「市政debug松 - 沈伯洋」）。
- 題目來源：「市長，你給我聽好了」收集的上千則市民抱怨與建議，整理成 **7 個市政痛點**，邀請工程師、設計師、資訊人用一天做出最小可行方案（MVP），「做為未來市政推動的方針」。
- 每隊選一題，也可跨題整合；每題附可用的開放資料。
- 已知題目：
  - #1 把樹種回來（2025 年台北有 3,164 棵樹被移除）
  - #2 找回消失的垃圾桶（行人垃圾桶由近 3,000 組減到約 800 組，結合人流、商圈、通報熱點做動態佈建建議）
  - #3–#7：搜尋摘錄沒有，未確認。

## 呼應政見：首都文化徑×山林徑（Seasu 指定，2026-10-13）
政見頁：https://puma.taipei/policies/台北文化徑×山林徑?pillar=h （原頁被擋，以下據 2026-09-08 記者會報導）
- 文化徑：四大主題文化徑，含「產業文化遺跡」（茶、煤礦、糖業）與「城市歷史記憶」（艋舺、大稻埕、城內、北投）。
- 山林徑：象山、劍潭、貓空設 3 座登山觀光中心（裝備租借、更衣、四語導覽、即時路況、生態預約），目標「亞洲第一觀光登山城」；步道以修復代替新建、數位導覽與安全應急平台。
- 四大主題：產業文化遺跡（文山茶園、南港茶廠、大稻埕老茶行；煤礦、糖業）、城市歷史記憶（艋舺、大稻埕、城內、北投）、多元族群敘事、人權與民主記憶。
- 五大推進策略：路徑品牌化、導入數位治理、提升場域易達性、深化在地參與、跨局處常態推動平台。
- 報導另提到四獸山與城市記憶的串連。登山中心預算約 5,000 萬元。

### 政見 PDF 原文重點（16 頁簡報，存於 references/policy-culture-mountain-trails.pdf）
- 開場：「台北 一座光榮的城市／群山環繞的城市」，兩大目標：串連首都文化徑（四大主題）、亞洲第一登山觀光城。
- 四大主題：產業文化遺跡（產業發展的集體記憶）、城市歷史記憶（從舊城到都會的成長軌跡）、多元族群敘事（包容與共榮的城市底蘊）、人權與民主記憶（民主之城的精神地標）。簡報本身沒列具體路線，地名來自報導。
- 登山觀光中心：象山（信義、象山站）、劍潭山（士林、劍潭站）、貓空（文山、動物園站／纜車起站）。服務：裝備租借、置物、更衣、中英日韓四語導覽、洗鞋、即時步道狀態、生態季節導覽預約。
- 生態友善步道：修復代替新建，「讓步道成歷史地景的載體」；最後一哩路接駁。
- 問題：資源分散缺品牌、市府整合不足、保存模式受限、缺跨域支持。
- 五層連結：空間（山林↔城市）、時間（歷史↔當代↔未來）、社會（居民、社區、青年、遊客）、行政（文化、工務、觀光、教育、交通）、區域（台北↔北台灣）。
- 五大執行策略：①路徑品牌化「走一條路，認識台北這座城」②數位治理「閱讀文化、認識生態，隨時隨地」③易達性「親子同行卡」④跨局處平台 ⑤在地參與「由台北裡的人，說自己的故事」。
- 結語：縮短市民與文化、山與城的距離，讓人說出「這是我的城市，我以它為榮」。

### 遊戲怎麼直接打中政見
| 政見 | 遊戲對應 |
|---|---|
| 山與城、歷史與當代的連結 | 《洋流》現世↔靈界本身就是「時間層」：喚醒地點時看見它的過去 |
| 路徑品牌化「走一條路」 | 遊戲關卡＝一條真實路徑（如大稻埕茶路、象山→四獸山） |
| 數位治理「隨時隨地閱讀文化、認識生態」 | 每個節點的圖鑑卡＝數位導覽內容 |
| 三座登山中心 | 象山、劍潭山、貓空做成三個山之節點／傳送點 |
| 青年、親子 | 手機遊戲的主要受眾，可設親子同行任務 |
| 在地參與「台北裡的人說自己的故事」 | 讓玩家或在地人留下地點故事（MVP 可先做留言卡） |
建議 MVP：台北一張小地圖，4 個文化節點（各代表一個主題：大稻埕茶＝產業、艋舺／城內＝城市記憶、北投＝多元族群（凱達格蘭、溫泉）、景美人權園區或二二八公園＝人權民主）＋3 個山節點（三座登山中心）。地點對應主題是我的建議，簡報沒指定。

### 遊戲對接建議
- 現有原型三個喚醒點（城之回聲／海之流痕／山之鐘聲）改落在台北：城之回聲→大稻埕或艋舺（茶、城市記憶），山之鐘聲→象山或貓空（茶山＋登山中心），可加北投、劍潭作第四點。
- 每個點喚醒時帶出真實地點與一句文化／山林故事，正好就是政見裡的「數位導覽」。
- 開放資料可接台北步道、古蹟／文化資產、景點清單，讓 Demo 有市政感。
- 提案一句話：用《洋流》讓年輕人在手機上先走一遍台北的文化徑與山林徑，再真的去走。
