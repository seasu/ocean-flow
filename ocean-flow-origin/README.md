# 洋流：起源 Ocean Flow: Origin

90 秒世界觀概念片的所有製作檔案。

| 目錄 | 內容 |
|---|---|
| [docs/](docs/) | 製作包、英文旁白稿、[製作紀錄](docs/production-log.md)（討論與決定）、[黑客松研究筆記](docs/hackathon.md)、參考資料 `references/` |
| [films/](films/) | 做好的影片成品（v1 靜態分鏡、v2 動態版） |
| [character-ref/](character-ref/) | 角色設定圖：藍色款（有／無耳機）、橘白款、四色系列 `four-colors/` |
| [film-v1/](film-v1/) | 成片產生腳本：關鍵畫面 `frames/`、特效圖層 `fx/`、`img.py` 生圖、`fx.py`、`build.py` 剪輯 |
| [film-js/](film-js/) | 網頁動畫版（GSAP＋canvas）、方塊世界 `world.js`、配樂 `music/` |
| [blocky-sample/](blocky-sample/) | 方塊風格單鏡樣片 |
| [voice-tests/](voice-tests/) | 旁白試音、定案旁白、TTS 腳本 `scripts/` |

`film-v1/build.py` 預設把成片輸出在 `film-v1/`，完成後請移到 `films/`。
