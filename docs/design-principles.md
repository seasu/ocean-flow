# 洋流 UI 設計原則

Seasu 定下的介面原則。新增或修改畫面前先對照這份，和設計規範（繁中預設、內文至少 16px、毛玻璃卡片、線條 icon、手機尺寸截圖驗證）一起用。

## 畫面
- **一次只呈現一個重要資訊。** 展開任務卡、雷達、靈界地圖、景點卡時，其他按鈕和控制項一律隱藏。
- **主視覺先墊底。** 背景要等程式載入才畫得出來時，先放一張靜態圖，不讓使用者只看到字和按鈕。
- **永遠滿版。** 瀏覽器和「加到主畫面」的全螢幕模式都要填到最下面，不能露出空白或黑邊。
- **預覽固定、清單捲動。** 上方是預覽或主要操作、下方是清單的頁面（例如角色搭配），只讓清單區自己捲動。

## 收藏類頁面
成就、物品收藏、台北集章簿用同一套樣式，之後新的收藏頁也照這套做：
- 分區標題：圓形線條 icon＋標題＋進度（例如 2/8）。
- 兩欄卡片，每張卡片是圓形大圖示、名稱、下方一行說明。
- 拿到的是彩色、金框；還沒拿到的是灰階。
- 點拿到的開滿版介紹；點還沒拿到的會搖一下。

## 文字
- **不放多餘的提示字。** 還沒拿到的項目只放簡介，不寫「走到現場蓋章」這類指示。
- **用語跟玩法一致。** 集章簿是走到景點附近就自動收集，用「收集」，不用「蓋章」。

## 互動
- **選擇不佔「無」的位置。** 像衣櫃這種選擇，不放「不戴」或「原本外套」：點一下選上、再點同一個取消、點別的直接換成那個。
