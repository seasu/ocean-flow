# 0002 世界觀採八章架構

- 日期：2026-10-14
- 狀態：已確認
- 來源：Seasu 提供的八階段圖（`ocean-flow-origin/world/eight-chapters.png`）

## 決定

八章：序章 起源（覺醒台灣）→ 第一章 流域 → 第二章 連界 → 第三章 星航 → 第四章 萬象 → 第五章 歸源 → 第六章 新生 → 終章 無界。取代原本「起源／彼岸／萬流」三部曲。像書的章節一樣慢慢揭開，遊戲設定內有世界觀章節頁。
