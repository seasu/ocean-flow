# 0007 UI 改動先過設計規範與設計原則

- 日期：2026-10-14、10-15、10-16
- 狀態：已確認
- 來源：Seasu

## 決定

- 任何介面、畫面、按鈕、文案、圖示的改動，先用 skill「ocean-flow-design-guideline」（洋流 UI 設計規範）檢視。載不到時照重點：預設繁中、內文至少 16px、留白充足、毛玻璃卡片、主按鈕靠下、線條 icon 不用 emoji。
- 同時對照 [docs/design-principles.md](../design-principles.md)，最重要的一條：**一次只呈現一個重要資訊**，展開卡片或地圖時其他控制項隱藏。
- 用手機尺寸 390×844 截圖驗證後才回報。

## 影響

QA Agent 驗收 UI 改動時要逐條對照，並附截圖。
