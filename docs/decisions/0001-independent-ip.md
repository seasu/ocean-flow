# 0001 獨立 IP，不把候選人、政黨、競選寫進故事

- 日期：2026-10-14（README 例外於 2026-10-16 確認）
- 狀態：已確認
- 來源：Seasu，專案討論

## 決定

- 《洋流》是獨立 IP。遊戲內的世界觀、故事、角色都不提候選人、政黨或競選。
- 台灣是世界第一個「啟流」的地方：「從台灣被發現，但不屬於台灣」。
- 例外：README 可以寫參加沈伯洋團隊「市政 Debug 松」的動機與政見來源（首都文化徑及山林徑）。

## 理由

遊戲要能長期經營、走向其他城市，不能綁在單一選舉事件上。

## 影響

所有文案、故事、景點卡都要守這條；只有 README 的專案說明可以提政策脈絡。
