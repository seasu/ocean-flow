# 0008 核心玩法：走路修行、靈光與機緣、四門小遊戲

- 日期：2026-10-15、10-16
- 狀態：已確認
- 來源：Seasu

## 決定

- 走路修行是基礎：真實 GPS 走路累積修為，五境界（感流、聚流、化流、御流、歸流）。
- 現世 × 靈界：靈光在靈界地圖上用搖桿收集；機緣只在實際 GPS 位置觸發。
- 開場選模式：「現世修行」記錄成就；「靈界走走」只體驗不記成就。
- 四門戰鬥：象＝數獨、虎＝Tap Hero（連點）、豹＝畫符、獅＝三消；等級加淨化力、機緣星等調難度。
- 序章 BOSS「濁淵」：四關連戰，需要靈光才能挑戰，沒一次通關就清空靈光。
- 觸發機緣先看景點介紹，讀到底才解鎖「領取靈光」與「開始挑戰」。
