# 《洋流》市府上任 100 天落地範圍

> 這份文件整理 100 天內可以做到的範圍，讓預算有清楚的對應。局處分工、時程與金額都是**團隊的估計**，需要與各局處確認。

## 一句話

100 天內，先把現在的 MVP 變成**一條真的能走、能玩、能在商圈兌換的示範路線**：從象山登山觀光中心出發，串起四獸山步道、信義商圈和台北城市故事。其他區域、原生 App 和多城市擴展，留到 100 天之後。

這和政見「先從代表性路線做示範，再逐步擴大到不同主題與區域」的推動藍圖一致。

## 範圍總覽

| | 100 天內會做 | 100 天後再做 |
|---|---|---|
| 路線 | 1 條示範路線：象山登山觀光中心＋四獸山＋信義商圈，加上現有 7 個台北城市故事 | 北劍潭、南貓空兩座登山中心的路線；四大主題文化徑的其他區域 |
| 平台 | 維持手機網頁（可加到主畫面），不用下載 | 原生 App（iOS／Android），精準計步與背景定位 |
| 帳號與紀錄 | 簡易帳號登入，靈光、成就、物品存在伺服器，換手機也還在 | 串接市府「台北通」 |
| 商圈信物 | 首批 5–10 家合作店家；一次性 QR Code 兌換、店家用手機網頁掃碼核銷 | 完整店家後台（自訂優惠、數量、期限）與兌換報表 |
| 防偽 | 伺服器保存紀錄、一次性兌換碼、速度過快不計 | 假定位偵測、藍牙 beacon 等現場驗證 |
| 內容 | 示範路線新增的地點與故事；文化局審訂；中英兩語 | 日韓語；內容後台，讓局處和商圈自己更新 |
| 安全 | 安全評估；接上步道封閉資料，封閉時自動停用該點 | 天候與夜間自動提醒 |
| 檢測 | 資安、個資與網站無障礙檢測 | 依檢測結果持續改善 |
| 數據 | 匿名統計各點到訪人數與兌換次數 | 給市府與商圈的成效儀表板 |

## 為什麼選象山這條路線

- 政見規劃的三座登山觀光中心裡，「東象山」串的是信義商圈和台北 101，商圈、交通和觀光客都最多。
- 遊戲第一階本來就是四獸山（象、虎、豹、獅），角色、戰鬥、故事都能直接沿用，只要把 Demo 用的會場周邊點位，換成步道口和商圈的真實地點。
- 捷運象山站到登山口的距離短，好走、好推廣，也方便規劃「最後一哩路」。

## 參與局處

| 局處 | 負責 |
|---|---|
| 觀光傳播局 | 主責單位；景點介紹與照片授權（臺北旅遊網）、推廣活動、翻譯 |
| 工務局大地工程處 | 四獸山步道資料、路況與封閉公告、步道上的安全點位與標示 |
| 文化局 | 城市故事與文化徑地點的內容審訂 |
| 產業發展局商業處 | 招募信義商圈合作店家、訂定「商圈信物」優惠與核銷規則 |
| 資訊局 | 開放資料介接、資安與個資檢測、網站上架 |

## 需要的資料

- 臺北旅遊網景點 Open API（已接上）
- 四獸山親山步道路線、出入口與里程（大地工程處）
- 步道即時路況與封閉公告
- 文化資產／古蹟清單與座標（文化局）
- 示範路線各點位的實地 GPS 座標與照片（現場踏查）
- 首批合作店家名單與優惠內容（商業處、商圈發展協會）

## 100 天時程

| 期間 | 工作 | 產出 |
|---|---|---|
| 第 1–30 天 | 確認主責局處、資料授權與合作商圈；選定示範路線點位；安全評估；設計帳號與兌換的後端 | 路線與點位清單、店家名單、系統設計 |
| 第 31–60 天 | 現場踏查校正座標、拍照；新地點的故事與問答撰寫、文化局審訂、英文翻譯；開發帳號、紀錄與兌換核銷 | 可內部試玩的版本 |
| 第 61–90 天 | 資安、個資與無障礙檢測；步道口、登山中心與合作店家設置 QR Code 立牌；邀請市民小規模試玩並修正 | 通過檢測的上線候選版 |
| 第 91–100 天 | 正式上線；搭配週末走讀活動推廣；首批店家開始兌換「商圈信物」；開始匿名統計 | 上線、第一份到訪與兌換數據 |

## 預算估計（新台幣）

| 項目 | 內容 | 估計 |
|---|---|---|
| 內容 | 新地點故事與問答、文案審訂、攝影、中英翻譯 | 30–50 萬 |
| 遊戲擴充 | 示範路線的新地點、物品與商圈信物美術、介面調整 | 60–100 萬 |
| 帳號與後端 | 帳號登入、伺服器紀錄、一次性兌換碼、店家核銷頁 | 80–120 萬 |
| 雲端主機 | 後端與資料庫，100 天＋上線初期 | 5–10 萬 |
| 檢測 | 資安、個資與網站無障礙檢測 | 20–40 萬 |
| 現場立牌 | 步道口、登山中心與合作店家，約 15 處 | 15–30 萬 |
| 推廣活動 | 週末走讀、合作店家宣傳 | 30–50 萬 |
| 專案管理 | 跨局處協調、店家聯繫、試玩營運 | 20–30 萬 |
| **合計** | | **約 260–430 萬** |

說明：
- 跟 MVP 比，最大的新增是「帳號與後端」，因為商圈信物要換成實體優惠，紀錄就不能只存在玩家手機裡。
- 原生 App 不在 100 天預算裡。先用手機網頁上線，確認大家願意走、店家願意配合，再決定要不要投入 App。
- 合作店家提供的優惠由店家自行負擔，不列入市府預算。

## 怎麼算成功

- 上線後一個月內，示範路線的到訪人次與完成四獸靈門的人數
- 商圈信物的兌換次數與合作店家數
- 試玩問卷：玩家是否因此第一次走四獸山步道、是否更認識路線上的歷史

這些指標都用匿名統計，不保存玩家的移動軌跡。
