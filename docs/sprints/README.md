# Sprint 看板

每個 Sprint 一個檔案（`sprint-NN.md`），一個 Sprint 一個 thread、一條分支（決策 0012）。Sprint 要小，做完一件可驗收的事就結束。

這裡是開發進度的唯一事實來源：thread 裡的進度清單只是即時顯示，新的 session 從這裡接手。

## 每個 Sprint 檔案要有

- 目標、分支、PR、狀態（規劃中／進行中／待驗收／完成）。
- 任務表：編號、任務、擁有的檔案、依賴、驗收條件、狀態、QA 結果。
- 需要 Product Owner 做或決定的事。
- 結束時的驗收紀錄：誰在什麼時候驗收、相關決策。
