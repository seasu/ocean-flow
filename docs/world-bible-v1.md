## 1. 作品定位

IP 名稱：《洋流》
第一部作品：《洋流：起源》

《洋流》不是單純的修仙故事，也不是一個以 GPS 打卡為核心的遊戲。

它描述的是：

**人類重新學會感知世界的時代。**

在這個世界裡，修行不是突然出現的新能力。

它是一套人類曾經理解、後來逐漸遺忘，如今又重新被發現的「世界感知方式」。

而第一次足以被大規模觀測、紀錄並證實的現象，發生在：

**台灣。**

因此，台灣不是《洋流》的唯一世界。

台灣是：

**起源。**

## 2. 核心命題

《洋流》的核心不是：

如何成為最強的人？

而是：

**人到底如何與這個世界產生連結？**

科技讓人類越來越了解物質世界。

但越來越多人開始感覺：

- 自己與自然失去連結
- 自己與土地失去關係
- 自己與其他人逐漸疏離
- 資訊越來越多，卻不知道自己要往哪裡去

就在這樣的時代，一種原本被視為迷信、傳說、宗教經驗、直覺甚至幻覺的現象，開始被不同的人同時觀察到。

有人看到光。
有人聽到聲音。
有人在同一座山做了相同的夢。
有人在沒有任何聯絡的情況下，描述出完全相同的景象。

人類第一次開始懷疑：

**世界是否還存在一個我們一直沒有真正理解的層次？**

## 3. 「流」

這個世界最核心的概念叫做：

**流**

流不是單純的能量。

也不是傳統意義上的「靈氣」。

它更接近：

**存在於萬物之間的關係、變化與方向。**

山有自己的流。
水有自己的流。
風有自己的流。
城市有人群形成的流。
文明有歷史形成的流。
一個人的情緒、意志、選擇與生命經驗，也會形成自己的流。

因此：

世界不是由一個個孤立的物件組成。

而是由無數彼此影響的「流」構成。

## 4. 洋流這個名字

「洋流」原本只是人類描述海洋水體運動的詞。

但在啟流之後，人類逐漸發現：

海洋中的洋流，只是「流」最容易被人類肉眼理解的一種形式。

更大的世界裡：

```
山有地流
河有水流
風有天流
城市有人流
思想有念流
生命有命流
```

所有這些流彼此交會。

而人，也存在於其中。

因此「洋流」最後成為一個新的時代詞彙：

**描述人類與世界重新產生連結的文明現象。**

## 5. 世界核心語句

《洋流》的世界觀核心可以濃縮成：

**山有脈，海有流，人亦有自己的道。**

另一句則是：

**靈界從未消失，只是人類曾經失去感知它的能力。**

而《洋流：起源》的核心主題：

**當人類重新開始感知世界，修行便不再只是傳說。**

## 6. 啟流

人類將第一次大規模、可重複、多人共同感知「流」的事件稱為：

**啟流**

啟流不是爆炸。
不是末日。
也不是某一天突然全球所有人獲得超能力。

最初，它非常微弱。

例如：

```
某些人在特定山區聽見不存在的鐘聲。

不同城市的人夢見同一座山門。

多人在同一地點看到短暫出現的光。

電子設備留下無法解釋的感測異常。

動物在特定時間朝同一方向移動。
```

一開始，這些事情被解釋成：

- 巧合
- 幻覺
- 網路模因
- 集體心理現象
- 儀器誤差

直到：

相同現象開始被大量人重複觀測。

人類終於無法忽視它。

## 7. 為什麼第一個啟流發生在台灣

台灣不是因為被「選中」。

而是因為台灣本身就是極度特殊的「流之交會點」。

從自然環境來看：

```
高山密集
板塊交界
海洋環繞
黑潮經過
季風交會
火山活動
溫泉
河川密集
森林多樣
地震頻繁
```

從人類活動來看：

```
高密度城市
多元文化
移民歷史
山海距離極近
現代科技與傳統信仰共存
```

在《洋流》的世界裡，這些條件意味著：

**台灣是一個不同種類「流」高度重疊的地方。**

因此當人類感知能力重新開始變化時，台灣最先出現了：

**共振。**

## 8. 台灣不是唯一的靈脈

這一點是整個 IP 未來發展最重要的設定。

世界各地原本就存在流。

例如：

```
火山
森林
沙漠
冰原
古城
峽谷
海洋
河流
人口密集城市
古文明遺址
```

都可能形成自己的流。

只是：

**台灣是人類第一個真正理解這個現象的地方。**

因此《洋流：起源》的結尾必須留下伏筆：

當台灣的流被完全觀測之後，人們才發現，世界其他地方早已有相似的訊號開始甦醒。

## 9. 現世與靈界

《洋流》的世界不是「現實世界 + 另一個異世界」。

比較準確的理解是：

**同一個世界的兩種感知狀態。**

### 現世

一般人所熟悉的物質世界。

包含：

- 城市
- 山脈
- 道路
- 建築
- 科技
- 社會

### 靈界

不是另一個宇宙。

而是：

**當人類能夠感知「流」之後，看見的世界層。**

同一座山，

現世看見：

```
樹
岩石
道路
氣候
```

靈界可能看見：

```
地脈
靈流
古老殘響
秘境入口
靈獸
宗門遺跡
```

兩個世界其實一直重疊。

## 10. 修行

傳統人類把類似現象稱為：

**修行**

但現代人重新理解之後發現：

修行不是單純累積能量。

修行真正的過程是：

```
感知
↓
理解
↓
連結
↓
調整
↓
掌握
```

修行者首先學會：

感覺世界正在如何流動。

之後才學會：

不被流帶走。

最後才可能：

改變流。

## 11. 境界

境界不是單純戰力等級。

每一個境界都代表人類對自己與世界關係的不同理解。

### 煉氣

開始感知流。

修行者第一次能察覺：

- 地脈
- 情緒
- 靈氣
- 危險
- 機緣

核心問題：

**我能不能聽見世界？**

### 築基

開始建立自己的內在秩序。

不再只是被外界的流影響。

核心問題：

**我是誰？**

### 金丹

形成屬於自己的穩定「內在之流」。

修行者開始真正產生自己的道路。

核心問題：

**我的流往哪裡去？**

### 元嬰

意識不再完全受限於肉體與單一空間。

能感知更大範圍的流。

核心問題：

**我與世界的邊界在哪裡？**

### 化神

修行者本身開始成為一個「流源」。

他的選擇、思想甚至存在方式，都能改變周圍世界。

核心問題：

**我的存在如何影響世界？**

## 12. 流派

世界中不是只有固定幾個流。

理論上：

**有萬流。**

但是人類最早整理出了若干基礎流。

例如：

### 赤流

概念：

- 行動
- 熱
- 突破
- 爆發

### 青流

概念：

- 生長
- 平衡
- 修復
- 自然

### 緋流

概念：

- 情感
- 連結
- 魅力
- 共鳴

### 紫流

概念：

- 感知
- 星象
- 未知
- 意識

### 玄流

概念：

- 水
- 變化
- 隱匿
- 適應

### 金流

概念：

- 結構
- 秩序
- 守護
- 法器

這些不是職業。

而是：

**理解世界的方法。**

## 13. 衍生流

當修行者逐漸深入，不同流可能：

```
融合
變異
重新理解
```

形成新的流。

例如：

```
赤流 + 紫流
→ 雷流

青流 + 玄流
→ 霧流

金流 + 赤流
→ 熔流
```

甚至可能出現：

```
風流
星流
夢流
影流
霜流
空流
時流
```

因此：

沒有人真正知道世界上有多少種流。

## 14. 創流

最高階修行者最重要的能力之一不是：

學更多技能。

而是：

**創造自己的流。**

創流代表：

一個人已經理解自己的道路到足以形成一套新的世界解釋方式。

這可以成為《洋流》後期最重要的玩家內容。

## 15. 宗門

啟流之後，人類發現：

有些古老宗派並不是完全虛構。

它們曾經保存過關於「流」的觀察與修行方法。

有些早已消失。
有些轉入地下。
有些以宗教、武術、哲學、民俗形式延續。

啟流後：

**宗門重新出現。**

## 16. 新宗門與舊宗門

宗門可以分成：

### 古宗

啟流前已存在。

保存古老傳承。

### 新宗

啟流後由現代修行者建立。

可能結合：

- 科學
- AI
- 感測器
- 傳統修行
- 心理學
- 身體訓練

因此《洋流》的宗門世界不是純古裝。

而是：

**新仙俠。**

## 17. 科技與修行

《洋流》不設定：

科技 vs 靈性。

兩者並不是敵人。

現代科學會開始研究：

```
流場
共振
感知
意識
地理異常
```

企業會嘗試商業化。
政府會研究風險與治理。
宗門則掌握人類長時間累積的主觀經驗。

最有趣的衝突之一就是：

**科學可以量測流，但是否真的理解流？**

## 18. 機緣

「機緣」是：

**一個人、一個地方、一個時間與某一道流短暫重合的瞬間。**

它不能完全被預測。

因此機緣可能來自：

```
地點
時間
事件
人
選擇
天氣
世界異象
宗門
現實探索
```

## 19. 機緣種類

### 世界機緣

在靈界探索觸發。

### 任務機緣

因選擇或關係產生。

### 時辰機緣

特定時間出現。

### 社交機緣

因人與人相遇產生。

### 世界事件機緣

整個世界共同經歷。

### 現世機緣

玩家真的走到現實世界某個地點。

這是《洋流》最特殊的機制之一。

## 20. 現世機緣

例如玩家在遊戲中得知：

大屯山出現異常。

玩家真的前往陽明山附近安全 POI。

Mobile Web 感應：

```
位置
+
時間
+
玩家身份
```

觸發：

**大屯靈印**

當玩家回到靈界，NPC 會知道：

這名玩家真的去過那個地方。

於是：

```
現世行動
↓
改變靈界
```

## 21. 跨世界修行歷程

這是《洋流》最重要的產品概念。

玩家角色的歷程不是只有：

```
Level 37
```

而是：

```
曾在陽明山取得大屯靈印

曾與三名宗門弟子共同開啟月門

曾在阿里山遇到青木傳承

曾參加第一次宗門大比

曾創立自己的宗門

曾發現一個新的流
```

這些共同構成：

**修行歷程。**

## 22. 玩家身份

玩家不是世界救世主。

玩家只是：

**啟流之後第一批真正開始理解這個世界的新世代修行者之一。**

因此所有玩家的存在都合理。

沒有唯一主角。

**世界本身才是主角。**

## 23. 台灣官方宗門

《起源》初期可以存在數個官方宗門。

例如：

### 聽潮宗

北境。

擅長：

- 感知
- 探索
- 機緣

### 青木門

阿里山一帶。

擅長：

- 生長
- 採集
- 煉丹

### 天衡宗

中央山脈。

擅長：

- 防禦
- 法器
- 陣法

### 赤霄宗

玉山附近。

擅長：

- 戰鬥
- 爆發
- 突破

後續再增加其他宗門。

## 24. 玩家開宗立派

玩家後期可以：

**創建自己的宗門。**

但是：

宗門不是玩家 Guild 換一個名字。

它是《洋流》的內容創造機制。

宗主可以設定：

- 名稱
- Logo
- 理念
- 主要流派
- 任務
- 活動
- 招生
- 地域
- 宗門文化

## 25. 宗門與真實地理

玩家宗門可以與真實台灣某個「靈域」產生關聯。

例如：

```
陽明山
阿里山
中央山脈
日月潭
花東縱谷
```

但真實 POI 必須由官方系統審核。

玩家不能隨意建立私人住宅或危險地點。

## 26. 秘境

秘境不是 Dungeon 的另一個名字。

它的世界觀定義是：

**當某種流在特定條件下形成暫時穩定的封閉空間。**

因此：

```
秘境可以突然出現
秘境可以消失
秘境可能每次不同
```

這讓 Live Ops 在世界觀上自然成立。

## 27. 怪物

怪物不一定都是「妖怪」。

可以分成：

### 靈獸

本來就是靈界生命。

### 異化生物

受流影響而改變。

### 殘響

由歷史、情緒、記憶凝聚。

### 流災

當流失衡時產生的異常。

這會比單純「殺妖獸升級」有更多故事空間。

## 28. 法器

法器是：

**幫助修行者感知、調整或放大流的工具。**

因此現代法器可以有很不同的外觀。

例如：

```
耳機
→ 神識法器

項鍊
→ 靈墜

鞋
→ 御風靴

外套
→ 靈裝
```

所以《洋流》的時尚設計完全可以是：

**Streetwear × Xianxia。**

## 29. Fashion

外觀在《洋流》不是無意義 Cosmetics。

它象徵：

- 流派
- 宗門
- 身份
- 修行歷程
- 成就

因此 Fashion Show 在世界內可以重新解釋成：

**仙姿大會**

展示的不只是漂亮。

而是：

**你如何表達自己的道。**

## 30. 宗門大比

宗門大比不是單純 PvP。

可以包含：

```
戰鬥
探索
身法
合作
煉器
Fashion
```

因為：

修行不只有戰力。

## 31. 現世不只是 GPS 地圖

現世探索的目標不是：

去一個地方打卡。

而是：

**重新理解一個地方。**

例如：

阿里山不只是：

```
GPS 座標
```

而是：

```
森林
雲海
鐵路
歷史
地方故事
青木流
```

因此《洋流》未來可以自然與：

- 旅遊
- 地方文化
- 自然教育
- 博物館
- 景點

產生合作。

## 32. 親子探索

《洋流》不鼓勵玩家前往：

- 危險山區
- 私人土地
- 不適合兒童的區域

現世 POI 應優先：

```
遊客中心
公園
博物館
公共景點
安全步道
車站
觀景區
```

核心理念：

**遊戲給家庭一個出去走走的理由。**

## 33. 海外玩家

人在海外也能完整玩：

```
宗門
修行
戰鬥
秘境
Fashion
社交
開宗立派
```

只有「台灣現世機緣」需要人在台灣。

但：

**現世機緣不能形成不可替代的主要戰力。**

因此海外玩家不會變成二等玩家。

## 34. 等價取得

例如：

台灣玩家：

```
真的到阿里山
→ 青木印
```

海外玩家：

```
完成青木七日試煉
→ 青木印
```

但是：

```
「現世行者・阿里山」
```

這種真實探索成就只能透過實際到訪獲得。

這代表：

```
Power
→ 可替代

History
→ 不可替代
```

## 35. 《洋流》的真正收藏品

不是：

```
一把 +1000 攻擊力的劍
```

而是：

**玩家自己的故事。**

例如：

```
我的第一個宗門

我的第一次現世機緣

我第一次去陽明山

第一次遇到秘境

第一次成為宗主

第一次創造新流
```

這些才構成《洋流》的長期身份。

## 36. 第一部：《洋流：起源》

第一部只講一件事：

**人類如何第一次發現流。**

故事範圍：

台灣。

## 37. 起源主線

可以從一系列小異常開始：

```
山區異象
↓
共同夢境
↓
多人共感
↓
第一次可驗證啟流
↓
古老宗門重新出現
↓
現代社會開始研究
↓
玩家開始修行
↓
台灣靈脈逐漸甦醒
```

玩家最終發現：

台灣並不是唯一存在流的地方。

## 38. 起源結尾

第一部最後：

玩家站在台灣東部海岸。

遠方海面出現一道以前從未觀察到的巨大流場。

研究系統顯示：

```
SOURCE UNKNOWN
```

它指向海的另一端。

然後出現：

《洋流》

**世界才剛開始。**

## 40. 最大的哲學問題

《洋流》最後可以慢慢觸碰：

- 人類意識只是大腦活動嗎？
- 世界與觀察者是否真的完全分離？
- 為什麼不同文明都曾發展出修行傳統？
- 靈界究竟是客觀存在，還是意識共同建構？
- 「流」是在世界裡，還是在人的感知裡？

《洋流》不必急著回答。

遊戲可以讓玩家自己探索。

## 41. 世界觀的重要原則

### 不宣稱現實超自然現象是真的

《洋流》是一個虛構世界。

真實台灣的：

- 山
- 海
- 地理
- 文化

可以成為創作靈感。

但：

```
靈脈
啟流
宗門
流
```

都是作品世界觀設定。

**Modern / Neo Xianxia**

仙山

現代城市

科技介面

道袍
+
Streetwear

法器

現代工業設計

古老宗門

## 43. 色彩

主品牌不使用單一流派色。

建議《洋流》本身：

```
Deep Ocean
White
Silver

```

六種流各有自己的色彩。

這讓 IP 不會被綁定單一角色或單一政治視覺。

## 45. 產品層級

《洋流》是 IP。

不是 Roblox 的附屬名稱。

產品架構：

```
《洋流》
│
├── 洋流：起源
│
├── 現世 Web
│   └── GPS / 台灣探索
│
├── 靈界
│   └── Roblox / 未來其他平台
│
├── Avatar / Fashion
│
├── Story / Video
│
└── Future Experiences
```

Roblox 只是：

**第一個能讓玩家真正進入靈界的 3D 世界入口。**

## 46. 《洋流》真正的核心體驗

不是：

```
打怪
```

不是：

```
GPS
```

不是：

```
Fashion
```

甚至不只是：

```
修仙
```

真正核心是：

**發現。**

```
發現一個地方
發現一道流
發現一段故事
發現一個人
發現自己的道路
```

因此每個系統都應該回到同一個問題：

**這個系統能不能讓玩家感覺，世界還有一些事情值得去發現？**

## 47. 《洋流》的長期願景

如果《洋流》有一天從台灣走到世界各地，玩家可能會擁有：

```
台灣・大屯靈印
日本・富士流印
冰島・火山流印
美國・峽谷流印
```

這些不是單純 Badge。

而是：

**玩家真的曾經走過世界的紀錄。**

最後形成：

**一個人的修行地圖。**

## 48. 最終核心

《洋流》的終極概念不是：

逃離現實。

而恰好相反。

**重新回到現實。**

遊戲讓玩家重新看見：

- 山
- 海
- 城市
- 人
- 自己

因此：

現世不是離開遊戲後的地方。

**現世本來就是《洋流》的一部分。**

## 49. 最核心的品牌句

**《洋流》不是建立在台灣之上的世界。**

**它是一個從台灣開始，被人類重新發現的第二世界。**
